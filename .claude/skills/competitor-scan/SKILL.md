# Competitor scan

1. If no names are given, find 5–8 real alternatives via web search (app stores, "X alternative", Reddit threads). Include the "do nothing / spreadsheet" alternative.
2. For each, record with source links: one-line positioning, price, main channels, an example of their messaging, and current ads (Meta Ad Library, TikTok Creative Center) when reachable.
3. Mine reviews and threads (1–3★ app reviews, Reddit) for repeated complaints; quote them exactly with links.
4. Write `projects/<slug>/competitors.md`:
   - comparison table
   - **gaps**: complaints nobody solves well, audiences nobody talks to
   - **angles for us**: 3–5, each tied to a gap and to proof we actually have
5. Everything stated must have a link. Mark anything you could not verify as unverified rather than guessing. Date the file — this goes stale.
